# 📊 Meta Ad Performance Dashboard

An interactive **Power BI dashboard** designed to analyze and monitor the performance of **Meta (Facebook & Instagram) advertising campaigns**.

The project transforms raw advertising data into meaningful insights using **data cleaning, transformation, KPI analysis, and interactive visualizations**.

---

## 📌 Project Overview

Digital advertising generates a large amount of campaign data, making it difficult to identify which campaigns, ads, and audiences are performing well.

This project provides a centralized dashboard to evaluate Meta advertising performance and helps answer questions such as:

* Which campaigns are performing the best?
* How much money is being spent on advertising?
* Which ads receive the highest engagement?
* What is the reach and impression of each campaign?
* How many clicks and conversions are generated?
* Which campaigns provide better return on advertising spend?
* Where can advertising performance be improved?

The main objectives of this project are:

## 📈 Key KPIs

The dashboard focuses on important advertising performance indicators such as:

* **Total Spend**
* **Total Impressions**
* **Total Reach**
* **Total Clicks**
* **CTR (Click-Through Rate)**
* **CPC (Cost Per Click)**
* **Conversions**
* **Conversion Rate**
* **ROAS (Return on Ad Spend)**

### Example KPI Formulas

**CTR**

```text
CTR = (Clicks / Impressions) × 100
```

**CPC**

```text
CPC = Total Spend / Clicks
```

**Conversion Rate**

```text
Conversion Rate = (Conversions / Clicks) × 100
```

**ROAS**

```text
ROAS = Revenue / Advertising Spend
```
